# Raw sources (local only, not on GitHub)

Raw downloads behind the files in data/, kept so a refresh can see what was used last time. See UPDATING.md.

- osm/: OpenStreetMap extracts of both parks from Oct 25, 2026 (points of interest, and building/footpath geometry), plus the matched park_places CSVs (before and after picking ride doors). © OpenStreetMap contributors, ODbL.
- park_hours/: Disney's official hours, Oct 24 to Dec 5, 2026, as collected from Disney's calendar.
- crowds/: Queue-Times daily crowd ratings, 2015-2019 and 2023 to Oct 23, 2026 (Disneyland park 16, California Adventure park 17).
- edit/: where scripts\export-dataset.ps1 puts a dataset's CSV for editing.
- weather/: where scripts\fetch-weather.ps1 saves Open-Meteo history.
