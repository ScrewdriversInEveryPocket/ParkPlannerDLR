# Changelog

What changed in each version. The version is the one in `version.js`, shown at the top of the app as "Version 1.202610.4". Since 1.202610.4 it is `1.YYYYMM.N`: the year and month, then which update of that month (starting at 1 each month; the three `2026/10/26 - vN` updates were October's first three). Before that: `2026/10/26 - v1` to `v3`, and plain numbers v19 to v54. Add a line here with every version bump, and tag the commit with `v` and the version (for example `v1.202610.4`; older tags `2026-10-26-v1`, `v44`), so you can go back to it. Versions before v19 weren't recorded.
